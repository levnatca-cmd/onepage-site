# Website direction survey

Date: 2026-11-07. Deliver five separate raster website concepts for a preference survey. This is visual exploration rather than an implementation change.

## Shared controls

- One 3:2 landscape, front-on desktop website view per concept.
- Same brand, navigation, headline, subtitle, main action and four capability labels.
- Comparable hero depth, content density, text size and CTA prominence.
- No invented client logos, testimonials, certifications, statistics or guaranteed outcomes.
- Neutral public labels A–E; style names remain in the internal prompt notes.
- Every final image is retained in this directory. Generation uses the built-in image tool.

## Premortem before generation

| Failure mode | Probability | Impact | Detection | Prevention / QA |
| --- | --- | --- | --- | --- |
| Five images are cosmetic recolors rather than distinct directions | High | High | Compare silhouette, layout, visual subject and typography | Assign five different compositions and visual languages |
| Different copy or CTA prominence biases the vote | High | High | Check the shared exact text and visible content depth | Repeat identical copy, CTA and framing constraints in every prompt |
| Generated text is illegible or misspelled | Medium | High | Inspect each returned image | Keep copy concise and regenerate a failed concept if needed |
| Mockups invent client proof or technical capabilities | Medium | Medium | Inspect visible labels and imagery | Use actual service scope and clearly generic product interfaces |
| Deliverables are lost in temporary output paths | Medium | High | Verify five workspace image files and a prompt manifest | Save every final image and its prompt; provide a sharing archive |

## Survey questions

Present A–E without revealing the style names and randomize the order where practical.

1. Which visual direction do you prefer?
2. What do you think this company offers?
3. Which version would make you most comfortable discussing a project?

## Verification outcomes

All five concepts were generated with the built-in image tool and visually reviewed. Each final PNG is 1536 by 1024 pixels. Shared brand, offer, navigation, actions and capability labels are legible across the set; no client proof or fabricated metrics were added. The five directions differ in composition, visual language and palette. Every image and the complete prompt set are saved locally. The sharing ZIP contains only neutral A–E filenames and survey instructions; internal style names and prompts are kept outside the ZIP. The archive passed its integrity check.
